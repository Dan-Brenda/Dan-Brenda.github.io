Bra sizes don't carry over from brand to brand, and no tool gave a woman her right size at whatever store she was shopping, so I built one. Measured Size is now live on the Chrome Web Store, Firefox Add-ons and the App Store, giving one honest answer in each brand's own size labels across 160+ brands. I wrote every spec and directed Claude Code through 450+ scoped phases, drawing on my background in operations and commercial solar analysis.
